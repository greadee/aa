# aa-contracts TypeScript bindings

TypeScript types mirroring the v2 schemas, for `aa-visualizer` and `aa-ui` consumers.

- Source: `v2/index.ts`.
- Check: `npm install && npm run typecheck` (TypeScript `tsc --noEmit`).
- The JSON Schema files under `../schemas/v2/` are the source of truth; these types must match them.
