## Responsibility

The GitHub OS: the process documentation for issue and sub-problem decomposition,
the module-update lifecycle, phase management, sprint planning, pull requests, code
review, audits, and the ADR/pitfall policy.

## Owns

- Issue and sub-problem decomposition, and the module-update lifecycle.
- Phase management, sprint planning, and pull-request conventions.
- Code-review, audit, and repository-reconstruction process.
- The ADR and pitfall policy (the ADR store itself lives in [docs/adr](../../adr/README.md)).

## Must not

- Own product code or module behavior.
