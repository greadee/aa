# Feature index

Feature documentation captures behavior that spans or sits beneath phases: how a capability works, how it is tested, and the pitfalls discovered while building it.

## Structure

```
docs/features/{feature}/
├── README.md          what the feature is and why it exists
├── implementation.md  how it works, key types and seams
├── testing.md         how it is verified
└── pitfalls.md        observed / cause / solution / regression protection / guidance
```

Every feature folder is reachable from this index.
